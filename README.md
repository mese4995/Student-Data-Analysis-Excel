# Student Data Analysis and Interactive Dashboard

## Project Overview

This project focuses on analyzing student data and creating an interactive Excel dashboard to explore academic and demographic indicators.

## Dataset

The analysis covers 1,631 students across 15 academic programs.

## Tools Used

- Microsoft Excel
- Power Query
- Pivot Tables and Pivot Charts
- Interactive Slicers

## Main Tasks

- Data cleaning and transformation using Power Query
- Creation of key performance indicators (KPIs)
- Analysis of student distribution by academic program
- Analysis of gender and scholarship distribution
- Development of interactive charts and dashboards
- Geographical data visualization

## Skills Demonstrated

Data analysis, data cleaning, business intelligence, dashboard design and data visualization.
